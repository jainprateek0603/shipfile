# E019: Invalid CPU and memory combination

Fargate only allows certain memory sizes for each CPU size. For example, 256 CPU units allow 512, 1024 or 2048 MiB.

## Example

```yaml
services:
  api:
    scale: { cpu: 256, memory: 4096 }
```

## Fix

Pick a memory size from the list in the help line, or raise `cpu`.
