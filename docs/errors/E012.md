# E012: Unknown resource in `uses`

`uses` lists the queues and databases a service may touch. Each entry must name a resource declared under `queues` or `databases`. Services are not allowed in `uses`: services call each other over HTTP.

## Example

```yaml
services:
  api:
    uses: [orders-qeue]   # typo
queues:
  orders-queue: {}
```

## Fix

Fix the name (the help line suggests the closest one), or declare the resource under `queues:` or `databases:`.
