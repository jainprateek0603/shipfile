# E003: Unknown field

The spec has a field Shipfile does not know. Every section rejects unknown fields, so a typo is never ignored silently. The help line suggests the closest known field.

## Example

```yaml
services:
  api:
    build: .
    prot: 3000      # did you mean `port`?
```

## Fix

Rename the field to the one suggested, or remove it. `shipfile schema` prints every allowed field.
