# E007: Unsupported spec version

The `version:` at the top says which spec format the file uses. This build of Shipfile understands version `1`.

## Example

```yaml
version: 2
```

## Fix

Set `version: 1`. If the file was written for a newer Shipfile, upgrade Shipfile. Once a new spec version exists, `shipfile migrate-spec` will rewrite older files.
