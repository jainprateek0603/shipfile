# E001: The spec is not valid YAML

The file could not be parsed as YAML: for example a tab used for indentation, an unclosed `[` or quote, or a key with inconsistent indentation.

## Example

```yaml
services:
  api:
	build: .        # a tab, not spaces
```

## Fix

Fix the YAML at the position shown. Indent with spaces only, and close every bracket and quote. An editor that reads the schema comment at the top of the file (`# yaml-language-server: $schema=...`) shows these errors as you type.
