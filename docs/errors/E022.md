# E022: Environment variable collision

A name in `env` or `secrets` clashes with another one, or with a variable Shipfile generates from `uses` (for example `ORDERS_QUEUE_URL` or `MAIN_DB_HOST`) or for every service (`AWS_REGION`).

## Example

```yaml
services:
  api:
    env:
      ORDERS_QUEUE_URL: http://example   # generated from `uses: [orders-queue]`
    uses: [orders-queue]
```

## Fix

Rename the variable. Generated variables are listed in docs/PLAN.md section 5.2.
