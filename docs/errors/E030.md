# E030: Runtime can't be detected

No `runtime` was given, and the service folder has no `package.json`, `pyproject.toml`, `go.mod` or `Cargo.toml` to detect one from, and no Dockerfile of its own.

## Example

```yaml
services:
  api:
    build: ./api      # empty folder
```

## Fix

Set `runtime:` (`node22`, `python3.13`, `go1.23`, `rust`), add the manifest file, or add your own Dockerfile.
