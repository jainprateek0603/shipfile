# E016: Public service without a health path

The load balancer only sends traffic to tasks that pass an HTTP health check, and the local runner waits on the same path. A public service needs `health`.

## Example

```yaml
services:
  api:
    public: true
    port: 3000        # no `health`
```

## Fix

Add `health: /healthz` (any path that returns 200 when the app is ready). Workers without HTTP can use `health_cmd` instead.
