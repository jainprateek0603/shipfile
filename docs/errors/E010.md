# E010: Invalid name

Application, service, queue, database, environment and plugin names end up in AWS resource names and DNS, so they must be DNS-safe: lowercase letters, digits and `-`, starting with a letter and not ending with `-`. Environment variable and secret names must be `UPPER_SNAKE_CASE`.

## Example

```yaml
services:
  Orders_API:     # uppercase and `_`
    build: .
```

## Fix

Rename it, for example `orders-api`, and update every `uses` entry and environment override that refers to it.
