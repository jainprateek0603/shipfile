# E011: A name is used twice

Services, queues and databases share one namespace, because their names become stack resource names and environment variable prefixes. A queue and a database can't both be called `orders`.

## Example

```yaml
queues:
  orders: {}
databases:
  orders:
    engine: postgres
```

## Fix

Rename one of them, for example `orders-queue` and `orders-db`.
