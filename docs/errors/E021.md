# E021: Environment override for something that does not exist

An entry under `environments.<env>` overrides a service, queue or database that is not declared in the base spec. Overrides can only change resources that exist; they can't add new ones, so every environment has the same shape.

## Example

```yaml
services:
  api: { build: . }
environments:
  prod:
    services:
      apii: { scale: { replicas: 2 } }
```

## Fix

Fix the name, or declare the resource in the base spec.
