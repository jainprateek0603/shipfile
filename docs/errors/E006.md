# E006: A value is not allowed

The value has the right type but is not one of the allowed values, or does not match the expected format. Examples: `engine: mysql`, `arch: amd64`, `cpu: 300`, a `health` path without a leading `/`, a `runtime` like `nodejs`, or an empty `command`, `migrate` or `health_cmd` list.

## Example

```yaml
aws:
  arch: amd64      # use `x86_64`
databases:
  main-db:
    engine: mysql  # `postgres` or `dynamodb`
```

## Fix

Use one of the values listed in the message.
